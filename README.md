### 🛠️ Projetos em destaque

**[📊 Gestão Financeira — Micro SaaS](https://github.com/dougllassillva27/contas-a-pagar2)** · `Node.js` `Express` `PostgreSQL` `Jest`
Aplicação web full-stack para controle de contas a pagar, com autenticação multi-usuário, deploy em nuvem e bot de automação com IA (WhatsApp, Telegram e Discord). Deploy no Render + Neon, com testes automatizados.

**[🗄️ SQL Server Suspect Recovery](https://github.com/dougllassillva27/sql-server-suspect)** · `Python` `PyQt5` `SQL Server`
Ferramenta desktop que automatiza a recuperação de bancos SQL Server em estado Suspect/Emergency: controle de serviços, correção de permissões e log detalhado de cada etapa.

**[🔎 Native Zoom Manager](https://github.com/dougllassillva27/zoomManager)** · `JavaScript` `Chrome MV3` `Supabase`
Extensão Chrome que gerencia zoom nativo por domínio, com persistência sincronizada entre dispositivos, compressão gzip e fallback para storage local.

**[🧮 Calculadora de Lanches](https://github.com/dougllassillva27/Calculadora-de-Lanches)** · `JavaScript` `pytest` `ESLint`
Aplicação web que processa arquivos de ponto (`.prn`, `.txt`, `.csv`, `.xlsx`), calcula intervalos de refeição e gera relatórios exportáveis, com testes automatizados.
